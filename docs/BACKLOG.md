# BACKLOG (локальный)

Необязательный локальный список задач. Без issue-трекера: пункт можно взять отсюда или
описать агенту прямо в сессии. Формулируй по [TASK_GUIDE.md](TASK_GUIDE.md)
(что · где · как проверить).

## Формат

```
- [ ] <feat|fix|chore>: краткое название
      Что: ...
      Где: ...
      Как проверить: ...
```

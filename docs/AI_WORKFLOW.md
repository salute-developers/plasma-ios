# AI-агентная инфра

В репозитории развёрнута локальная инфраструктура для работы с AI-агентом (Claude Code).
Этот файл объясняет, что за служебные каталоги лежат в git и зачем они.

Для внешнего читателя всё описанное здесь — необязательное: репозиторий собирается и
разрабатывается без единого из этих инструментов, см. [BUILD.md](BUILD.md).

## Что лежит в git и зачем

| Путь | Что это |
|---|---|
| [`CLAUDE.md`](../CLAUDE.md) | карта репозитория для агента: где что лежит, команды, грабли |
| `<пакет>/CLAUDE.md` | тонкая надстройка над `README.md` пакета: только агентские заметки |
| [`.claude/memory/`](../.claude/memory) | память команды между сессиями; индекс — `MEMORY.md` |
| `.claude/skills/`, `.claude/commands/` | переиспользуемые сценарии и слэш-команды |
| [`.mcp.json`](../.mcp.json) | MCP-серверы сессии, в том числе граф-навигация по коду (Serena) |
| [`openspec/`](../openspec) | spec-driven workflow: предложения изменений и спеки (`/opsx:*`) |
| [`docs/plans/`](plans) | разовые планы и дизайн-доки, не оформленные как OpenSpec-изменение |
| [`project.yml`](project.yml) | контракт переносимости пакетов и знаний |

`.claude/settings.local.json` в git не коммитится — это локальные настройки разработчика.

## Как устроена документация

`README.md` пакета — источник правды для человека и для агента: что это, структура, сборка,
использование. `CLAUDE.md` рядом держит только то, что нужно агенту: грабли, коммит-скоуп и
ссылку на README. Содержимое README в CLAUDE.md не дублируется, иначе файлы разъезжаются.

## Правила биллинга

Агентная работа ведётся в интерактивном Claude Code.

- `ANTHROPIC_API_KEY` держим **unset**.
- `claude -p` / headless не используем.
- Результат проверяется локально и просматривается владельцем перед мержем.

Детали — [`.claude/memory/local-mode-billing.md`](../.claude/memory/local-mode-billing.md).

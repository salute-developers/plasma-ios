# Как ставить задачу агенту (plasma-ios)

Задачи ставятся **локально** — прямо в сессии Claude Code (или в [BACKLOG.md](BACKLOG.md)).
Чтобы агент сделал ровно нужное, задача должна отвечать на три вопроса:

1. **Что** нужно — конкретный результат (не «улучши», а «добавь X / почини Y»).
2. **Где** — пакет/файл/компонент (используй карту в корневом [CLAUDE.md](../CLAUDE.md)).
3. **Как проверить** — критерий готовности (сборка/тест/линт/визуальный осмотр).

Добавляй ограничения («не трогай сгенерированные `Themes/*`», «без новых зависимостей»)
и, для багов, шаги воспроизведения.

## Шаблоны

**Фича:**
```
Что: <новое поведение/компонент>
Где: <пакет/файл; напр. SDDSComponents/Sources/SDDSComponents/...>
Как проверить: <тест/сборка схемы/скриншот в SDDSDemoApp>
Ограничения: <не менять публичное API X; регенерировать темы, если тронул appearance>
```

**Баг:**
```
Симптом: <что наблюдается>
Воспроизведение: <шаги, схема, симулятор>
Ожидается: <корректное поведение>
Где искать: <пакет/экран; или "не знаю — найди">
Как проверить фикс: <тест/сценарий>
```

## Хорошо vs плохо

| Плохо | Хорошо |
|---|---|
| «Почини кнопку» | «Bug: в `SDDSDemoAppPlasmaHomeDS` у `BasicButton` в disabled-состоянии неверный цвет фона. Ожидается токен `surfaceSolidDisabled`. Где: `SDDSComponents` BasicButton appearance. Проверить: снапшот-тест + визуально в песочнице.» |
| «Добавь поддержку темы» | «Feat: сгенерировать пакет темы `NewVerticalTheme` из её `.sdds`-схемы. Где: конвейер `scripts/generate_themes`. Проверить: `SDDSDemoAppNewVertical` собирается и запускается.» |
| «Оптимизируй иконки» | «Chore: перегенерировать `SDDSIcons/Generated` после добавления иконки `iconFoo` в ассеты. Проверить: сборка `SDDSComponents`, `Asset.iconFoo` доступен.» |

## Подсказки

- Дай агенту прочитать нужный `CLAUDE.md` (он и так должен) — не пересказывай структуру.
- Для фич запускай **OpenSpec** (`/opsx:propose ...`) — спека фиксирует «что · где · как
  проверить» в `openspec/changes/` до реализации.
- Для широкого поиска по коду проси использовать **Serena** (граф), не `grep`.
- Одна задача = один логический коммит. Крупную дели на пункты.
- Если задача трогает публичное appearance-API компонентов — явно попроси регенерировать
  затронутые `Themes/*` и проверить сборку.

Вся AI-агентная работа в этом репозитории ведётся **только в интерактивном Claude Code**
в рамках подписки. Метерный API (оплата по токенам) не используется.

**Правила:**
- `ANTHROPIC_API_KEY` держать **UNSET** (наличие ключа переключает на метерный биллинг).
- **Не** использовать `claude -p` / headless-режим — это метерные вызовы.
- **Никаких** GitHub Actions / workflow с вызовом Claude и никакого `ANTHROPIC_API_KEY`
  в CI. В репозитории намеренно **нет** `.github/`-автоматизации для агентов.
- Проверка результата — **локально** (сборка/линт/тесты, если есть, иначе ручной осмотр)
  + просмотр владельцем. Ревью — `/code-review` в подписке.
- Проект без бэкенда, без CI и без issue-трекера: задачи ставятся локально (описываются
  агенту в сессии или берутся из `docs/BACKLOG.md`).

**Почему:** удерживает стоимость в рамках фиксированной подписки и исключает случайные
метерные списания. **Как применять:** перед запуском агента проверь `echo $ANTHROPIC_API_KEY`
(должно быть пусто); работай в интерактивной сессии `claude`, не в `-p`.
